Getting Started

Welcome to Attendance Tracker for Zoom! This guide will help you get started with tracking late attendees in your Zoom meetings.

How to Use

  1. Log in to your Zoom account on the web
  2. Navigate to Reports → Usage Reports
  3. Download the participant report as a CSV file
  4. Open Attendance Tracker for Zoom
  5. Import the CSV file (drag & drop or use file picker)
  6. Set your meeting start date and time
  7. View the list of late attendees
  8. Use the copy button to copy all names to clipboard

Frequently Asked Questions

Does this app require an internet connection?

No! The app works completely offline. All processing happens on your device.

Is my data safe?

Yes! The app doesn't send any data to external servers. Everything stays on your device.

Do I need to create an account?

No account is required. Just download and start using the app.

What CSV format is supported?

The app supports the standard Zoom participant report CSV format downloaded from the Zoom usage reports portal.

Can I customize the meeting start time?

Yes! You can set any date and time, and the app will show attendees who joined after that time.

Troubleshooting

CSV file not importing

  • Ensure you're using the participant report from Zoom's usage reports, not other export formats.
  • Check that the CSV file is not corrupted or empty.
  • Try re-downloading the report from Zoom.

No late attendees showing

  • Verify that your selected meeting start time is correct. Attendees who joined before this time won't be marked as late.
  • Check if the CSV file contains the expected participant data.
  • Ensure the date and time format in the CSV matches expectations.

App appears stuck or frozen

  • Try closing and reopening the app.
  • For large CSV files, the processing may take a few moments—please wait.
  • Ensure your device has sufficient memory available.
